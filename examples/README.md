# Examples

Three runnable scripts, one arc: **offline → portable → cross-vendor.** Each is
real — copy, run, watch it work.

```sh
python examples/01_quickstart.py
python examples/02_portability.py
python examples/03_cross_vendor.py
```

## 01 — Quickstart (offline)

A portable soul in five lines, no account. `etch` writes facts; `recall` reads
them back, ranked by priority then recency. This is the whole loop — local, instant.

## 02 — It's just a file

A soul is `vnd.fafm+yaml` — plain text you can read with your own eyes, diff, and
commit to git. No database, no proprietary blob. Run it and you see the raw soul
printed: that *is* your memory, in the open.

## 03 — Cross-vendor (the lock-in breaker)

The SDK writes a `.fafm`; **grok-faf-voice reads the same file with its own
reader.** Different vendor, same soul, zero conversion. That's the point of an
open format: your agent's memory isn't trapped in one model's walled garden.

The read half runs for real if `grok-faf-voice` is installed; either way the
write half proves the file is the shared format.

## The demo soul — [`demo.fafm`](./demo.fafm)

10 curated facts *about `.fafm` itself* (never personal memory). Generated by:

```sh
claude-fafm-sdk init --demo --file examples/demo.fafm
```

Try `claude-fafm-sdk recall fafm` against it.

## Receipts — what's actually verified

- **Format (self-verified):** the SDK writes `vnd.fafm+yaml` **v1.1** — the
  canonical format, shown plainly in [`demo.fafm`](./demo.fafm). The same shape
  `fafm-engine` and `grok-faf-voice` read.
- **Cross-vendor (verified end-to-end):** the Claude-native memory tool → `.fafm`
  → grok-faf-voice read roundtrip was verified in grok-faf-voice **v0.3.0 and
  v0.3.1** (a real Claude-written soul, read back perfectly). Reproduce the open
  half with `03_cross_vendor.py`.
- **Honesty note:** counts are always real. A fresh `init` soul has **0** facts;
  `--demo` has exactly the **10** it seeds. The 131-fact roundtrip was a genuine
  personal-memory test (the receipt that it scales) — *not* a shipped demo, and
  never quoted as the output of a fresh soul.
